# Harness Mistakes

This folder records repeatable mistakes observed during harnessed work.

The goal is to prevent the same error from recurring by keeping domain rules and category rules visible.

## Navigation

- Root hub: `docs/HarnessMistakes/README.md`
- Domain index: `docs/HarnessMistakes/domains/README.md`
- Category index: `docs/HarnessMistakes/categories/README.md`

## Usage Rules

- Classify one primary domain first.
- Read that domain file before reading extra category files.
- When a mistake is confirmed, append a short incident entry to the relevant category file.
- If the lesson changes normal operating rules, mirror it into AGENTS, CLAUDE, the prompt templates, or the validation tools.
