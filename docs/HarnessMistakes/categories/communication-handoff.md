# Communication Handoff Mistakes

## Definition

사용자에게 확인을 받아야 할 지점, 수동 실행 요청, 상태 보고, 완료 판정 전달이 부정확해서 생긴 실수입니다.

## Typical Signals

- 사용자가 무엇을 해야 하는지 타이밍이 모호함
- 완료라고 했지만 실제로는 사용자 실행 대기 상태였음
- 에디터 수동 작업이 필요한데 자동 완료처럼 보고함

## Prevention Rules

- 에디터에서 수동으로 해야 할 작업이 있으면 보고서 마지막에 명시한다
- "완료"는 검증까지 끝났을 때만 쓴다. 에디터 작업이 남아있으면 "코드 완료, 에디터 확인 필요"처럼 구분한다
- PR 병합 전 사용자가 해야 할 씬/프리팹 작업을 PR 본문에 후속 작업으로 남긴다
