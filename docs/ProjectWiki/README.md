# ProjectWiki

ProjectWiki is the durable knowledge store for this repository.

Use it for:

- stable system notes
- asset/reference notes
- architecture decision records
- accumulated project knowledge worth reusing later

Do not use it as an inbox. Use `docs/AgentHandoffs/**` for active cross-agent transfer.

## Structure

```text
docs/ProjectWiki/
├── README.md
├── index.md
├── log.md
├── systems/
├── assets/
└── adr/
```

## Rules

- add each new page to `index.md`
- append notable wiki updates to `log.md`
- keep pages short and specific
- if code and wiki disagree, update the wiki
